# LASERTOOL v4

這版主要重做 UI 與操作流程，保留 v3 的影像處理功能。

## v4 UI 改進
- 專業深色工具介面
- 左側固定控制欄、右側大預覽區
- 快速模式：照片網點 / 黑白線稿 / 雷雕清晰 / DXF 輪廓
- 常用與進階參數分區
- 原圖對照
- 預覽縮放與適合畫面
- 底部固定輸出列
- 手機版自動改為直向版面
